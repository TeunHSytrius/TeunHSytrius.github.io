Formula 1 Dashboard

Een applicatie waarmee Formula 1-gegevens overzichtelijk kunnen worden weergegeven. Gebruikers kunnen onder andere informatie over seizoenen, races, coureurs en teams bekijken.

Gebruikte technologieën

React ASP.NET Core C# REST API

Doel van het project

Het doel van dit project is om data uit een externe Formula 1 API te verwerken en deze op een duidelijke en gebruiksvriendelijke manier te presenteren.

Functionaliteiten

  • Formula 1-seizoenen bekijken
  • Races per seizoen bekijken
  • Coureurs bekijken
  • Teams bekijken
  • Race-resultaten bekijken
  • Punten per race bekijken

Wat heb ik geleerd?

Tijdens dit project leer ik meer over het werken met API's, het verwerken van JSON-data en het opbouwen van een full-stack applicatie.

Campus EventDesk

Campus EventDesk is een casus waarbij een databasesysteem wordt ontworpen voor het beheren van onderwijsgerelateerde activiteiten en deelnemers.

Gebruikte technologieën

SQL MySQL UML Database Design

Doel van het project

Het doel van het project is om vanuit een casus een correct conceptueel en logisch datamodel te ontwerpen en dit uiteindelijk te vertalen naar een relationele database.

Onderdelen van het project

  • Casusanalyse
  • UML-klassendiagram
  • Specialisaties
  • Associaties en multipliciteiten
  • Relationeel model
  • Database implementatie

Wat heb ik geleerd?

Tijdens dit project leer ik hoe ik bedrijfsregels uit een casus omzet naar entiteiten, relaties, attributen en uiteindelijk een relationeel databaseschema.
